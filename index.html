How I support clients

Code is half the job. The other half is people.

When a site breaks or a client needs a change, they need calm, clear help, not jargon. Here’s how I handle every request.

  1. 01

    Triage first

    Work out what’s urgent, what’s broken and who needs to know, before touching anything.

  2. 02

    Clear, friendly updates

    Plain-language replies so clients always know what’s happening and when.

  3. 03

    Ask good questions

    If a request is unclear, I ask, instead of guessing and redoing the work.

  4. 04

    Document as I go

    Notes and handovers so the next person can pick it up without starting over.

AI, but checked:
