About me

Curious about how good websites work.

It started with curiosity. I’d open a website, wonder how it was built, and pull it apart until I understood it. That habit led me to Computer Science at Xavier University – Ateneo de Cagayan, and now to building websites of my own from Cagayan de Oro.

I design in Figma, build with HTML, CSS, JavaScript, React and Python (Flask), and work in VS Code with Git. Claude, ChatGPT and Gemini help me learn and debug faster, but I test everything myself. For example, I throw empty and invalid inputs at AI-written form code before I trust it.
